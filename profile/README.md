# Black Candle Labs

Black Candle Labs is the research and development organization of [Black Candle Technologies](https://github.com/black-candle-technologies). This is where prototypes, experiments, and open source work live before they graduate into products.

The wider Black Candle footprint on GitHub spans three organizations:

- **[black-candle-technologies](https://github.com/black-candle-technologies)**: products and client work (Courier, Lumen, OpenMGMT, Script Control Software)
- **[blackcandlelabs](https://github.com/blackcandlelabs)**: R&D, prototypes, and experiments
- **[Black-Candle-Administration](https://github.com/Black-Candle-Administration)**: infrastructure and administration

## What we are working on

- **Courier**: an encrypted relay and messaging layer for AI agents and the humans who run them
- **Lumen**: local persistent agents with a command center
- **OpenMGMT**: open management tooling
- **Script Control Software**: control plane experiments

Stats above cover all three Black Candle organizations and refresh automatically.
